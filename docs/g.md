# Copying, Moving and Deleting Files

Make sure you are in the directory called __CLI__.

The format of the __copy__ command is __cp__ _source destination_

This will copy from an existing file (source) to a new file (destination) leaving the original file where it was.

To move a file, the command in Unix is __mv__ _source destination_, this will move an existing file (source) to a new location (destination) removing the original file.

To delete a file in Unix, the format of the command is __rm__ _filename_ This will delete a file (filename).
